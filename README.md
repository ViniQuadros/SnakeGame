
# Snake Game

A lightweight browser game inspired by the classic Snake, created as a hands-on project to explore game logic, user input, DOM manipulation, and real-time interactions using vanilla web technologies.

## Build with
- HTML
- CSS
- JavaScript

## Features

- A functional browser game
- Score counter
- Sound effects

## Run Locally

Clone the project

```bash
git clone https://github.com/ViniQuadros/SnakeGame
```

Go to the project directory

```bash
  cd SnakeGame/
```

If possible, use Live Server on VS Code to run the application.
